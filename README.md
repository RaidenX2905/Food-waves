## Architecture

- **Frontend**: Single Page Application built with React, Vite, and Tailwind CSS. Features smooth Framer Motion micro-interactions, responsive mobile navigation, and optimized asset loading.
- **Backend API**: RESTful Express service with MVC architecture, Helmet security headers, input validation, and CORS protection.
- **Database & Resilience**: MongoDB Atlas integration with graceful mock data fallbacks for zero-downtime offline previews.

## Local Setup

### 1. Backend Server

```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Client

```bash
cd frontend
npm install
npm run dev
```
